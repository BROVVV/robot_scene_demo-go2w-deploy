## 未满足的功能等价门

1. D435 已通过有线 30 分钟 RGB-D 长稳和相机坐标定位；地图坐标定位及建图/搜索实流
   验收尚未完成。断连时旧相机脚本曾因 `except rs.error` 属性不存在而退出采集
   线程；release 源码已改为 `RuntimeError`，原有 systemd 脚本尚未切换。
2. `wlan0` 当前不存在/未上线；用户决定无线网卡后续再接。浏览器无线访问、
   D435+Wi-Fi 并发 30 分钟、无线带宽与断线安全验收不能进行，保留网线。
3. Foxy 缺 `nav2_velocity_smoother`、`nav2_collision_monitor`、
   `nav2_behaviors`；执行链不能声称与 Humble 等价。静止 2D 地图与唯一 TF 已实测，
   但定位健康在 15 秒内仅 52/151 次通过，扫描帧龄 P50/P95 分别约
   0.204/0.389 秒，建图扫描约 0.259/0.447 秒；`scan_fresh` 与
   `mapping_scan_fresh` 间歇阻塞。只规划 Nav2 尚不能声明通过，执行链保持封锁。
4. YOLOE-PF 推理和相机坐标定位已通过短时验收，但 Ultralytics 8.4.190 的
   元数据要求 `polars>=0.20.0`，当前 Python 3.8/aarch64 可用 wheel 为 0.19.12；
   真实推理能运行，依赖元数据未完全闭合，不能声明 ML 环境可复现完整锁定。
   VLM 复核、持续相机输入和语义质量尚未验收。
   遥操建图单轮烟雾测试已在充电后用 90 秒 YOLOE 冷启动配置通过；
   地图坐标、语义质量、录像及连续会话仍需验收。
5. 机身 LiDAR 原始时间戳偏移约 19 分钟。现有桥能转换为本机时钟，但尚未接入
   完整 SLAM/TF；`/utlidar/robot_odom` 与 `/wirelesscontroller` 在 5 秒只读采样中
   没有收到消息。外置 Pandar 已在电脑和机器狗两端完成诊断点云验收，
   但其安装变换、全身外形包络、时间对齐和安全链仍未验收。
6. 遥操建图已通过单帧相机坐标烟雾测试，静止 2D 地图链路能出栅格，但
   YOLOE/VLM 持续语义落图、录像、回放、遥操行驶与自主搜索等真机功能等价测试
   仍未完成；不执行真实运动，也不切换 `robotscene_current`。
7. 电量从先前的 **12%** 充至约 **80%**，原预检的 Foxy 兼容问题已修复并在
   遥操建图烟雾测试中通过；后续静止建图试验实测最低约 69%。长时间验收仍需持续监视电量；原
   `realsense-stream`、`local-vlm` 服务运行正常。

## 现场继续验收顺序

1. 优化 Foxy 上激光预处理与 2D mapping 的实际帧龄，再重复 30 分钟只读定位健康采样，保持现有安全阈值。
2. 对已构建 Foxy ROS 包继续运行只规划 Nav2 与时间戳验收；Pandar 组播维持诊断隔离。
3. 完成 YOLOE 常驻输入、VLM 复核及语义质量验收，并消除依赖元数据不一致。
4. 按原入口逐项验收遥操建图和只规划自主搜索；保持点云 Web 开关关闭。
5. 用户后续接入无线网卡时，再完成 D435+Wi-Fi 30 分钟并发测试。
6. 只有补齐 Foxy 执行链并现场通过全部运动安全门后，才进入受监督短距离运动与生产切换。
