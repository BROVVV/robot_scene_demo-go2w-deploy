## 已复现的问题及修改

`scripts/go2w/setup_environment.sh` 加载基础 ROS 和 overlay 后执行 `set -u`，原失败码可能被覆盖；各层调用方也未显式返回加载错误。诊断脚本关闭 errexit，或在 `if source ...` 中调用时，可在加载失败后继续加载后续层、写入 DDS 配置并报告环境就绪。

用临时基础 ROS 和九个 overlay 脚本复现。最初16项新测试中11项失败、5项通过；11项均为真实非零返回被误报成功的反例，原始日志保留在 `before.log`。这些是受控 shell 夹具，不是真机上发生11次故障。

修改后，加载基础 ROS 或任一已选择的 overlay 返回非零时，保留原退出码、输出出错路径，并立即从环境入口返回；不加载后续层、不生成新的 DDS 配置，也不输出就绪。保留原有源选择规则，包括跨发行版记录使用 local_setup、厂商路径别名使用完整 setup，以及电脑默认可选缺失 overlay 的行为。原生 Foxy overlay 缺失或发行版不符仍拒绝加载。
