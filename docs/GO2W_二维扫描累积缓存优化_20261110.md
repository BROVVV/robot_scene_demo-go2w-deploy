# 二维扫描累积缓存优化（2026-11-10）

本次修改 `MappingScanAccumulator`，不需要机器人移动。原算法每次组装二维扫描时，都会把窗口内所有历史扫描按各自已保存位姿重新转换到世界坐标；这些历史扫描和位姿已经固定。本次只缓存该二维转换结果，每次仍按当前输入位姿重新投影、分箱、取最近距离，并保留当前扫描的全部有效返回。

## 保留的行为

- 0.75秒窗口、0.60秒预填充、32帧上限、0.0125米最大端点对齐误差和所有量程/角度规则不变。
- 运动清空历史、超时/时钟回退、几何改变、首次预填充、原始移动扫描与关键帧策略不变。
- 缓存只依附仍在窗口内的历史帧；过期、容量淘汰、移动清空及reset均同步删除。帧数组内部只读，调用者修改输入或返回结果不能污染历史。
- 不缓存当前机器人测量，不修改IMU/姿态/TF新鲜度、不调整自身反射表面或近距阈值。此组件仅用于原有二维结构扫描累积，不介入硬碰撞扫描和净空路径，不建立三维点云地图。

电脑和Jetson Python3.8各29项测试通过。新测试使用冻结的未缓存算法作为独立对照，覆盖2,160个随机/边界步骤：全圆与部分视场、8/97/720及改变后的bin数量、微小漂移与真实移动清空、yaw跨界、时钟回退/丢帧、几何变化、非有限距离、当前近障碍优先、unknown保持、输入/返回值所有权与缓存上限。输出dtype、数组字节和状态字典逐项一致。Jetson的38条warning来自测试刻意加入NaN后的NumPy比较，保留日志，不写成零warning。
