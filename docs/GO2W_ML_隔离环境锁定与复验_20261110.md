# GO2-W ML 环境锁定与复验（2026-11-10）

本轮形成 `requirements/robot-ml-jetpack51.lock`，用于 aarch64、CPython 3.8、JetPack 5.1.1 的独立 ML 环境。36 个包均固定版本和 wheel SHA-256。电脑原环境、机器狗原 `ml-jetpack51` 环境和历史 wheel 清单保持原样；锁文件不是电脑端安装清单，也不触发生产切换。

## 已完成验证

- 新 boot `c1ef36d2-ac9a-4daa-b86c-6bb1eb7df05a` 上，Polars 0.20.31 ARM wheel 在临时目录实际加载；固定 Ultralytics 8.4.190 wheel 内 DataExportMixin 的 DataFrame、CSV、JSON 导出通过。
- 先在独立副本验证兼容性，再用 `python3 -m venv --without-pip --copies` 创建完全空白的 `robotscene_runtime/venvs/ml-jetpack51-20261110-isolated`。该环境不继承系统 site-packages，没有从原 venv 复制包。
- 使用已校验的 pip 24.0 wheel 引导；随后全部 36 个固定 wheel 以 `--no-index --require-hashes` 离线安装成功。`pip check` 返回 0、`No broken requirements found`。
- 保持 NVIDIA Torch 2.0.0+nv23.05、TorchVision 0.15.1a0、Ultralytics 8.4.190、NumPy 1.23.5 和原模型。Polars 改为 0.20.31，满足 Ultralytics 的 `polars>=0.20.0` 要求。wheel 元数据规范化显示 Torch 2.0.0+nv23.5，与运行时版本字符串中的 nv23.05 为同一版本。
- 同一张 SHA-256 为 `516b1a8b9efc4b2bd0a17be6e6e1693a8db249db21f5ef3c52c8837062761e04` 的真实保存图，保持 CUDA:0、FP16、640 输入、confidence 0.25、IoU 0.5、retina masks。新副本、空白环境与此前机器狗基准均输出 20 个检测，类别、框、置信度、掩码像素数和掩码 SHA 全部逐项一致；未回退 CPU。
- 该基准仅是一帧功能/数值回归，不是检测准确率数据集，也不是完整并发、目标地图定位或真实行走验收。

## 原系统包与隔离范围

原 ML venv 继承系统包，`pip check` 有三项：系统 launchpadlib 缺 testresources、系统 onnx-graphsurgeon 缺 onnx，以及 Polars 版本过低。本轮没有删除、修改或假装修复系统包。新环境完全不继承它们，独立补齐 cycler、kiwisolver、packaging、pyparsing、python-dateutil、certifi、idna、urllib3、PyYAML 和 six；版本、官方 wheel URL、目标 ABI 与 SHA 记录在项目外 `acceptance_20261110_resume/ml_support_wheels/manifest.json`。

Debian 原 venv 的 `pkg-resources==0.0.0` 是占位元数据，不是独立运行依赖；空白环境没有引入它。setuptools 44.0.0 取固定官方 wheel，纳入完整锁文件。

## 复现与回退

必须使用 Jetson `/usr/bin/python3` 创建**新的**空白 venv，不能对电脑环境或当前环境执行安装。引导 pip wheel SHA 为 `ba0d021a166865d2265246961bec0152ff124de910c5cc39f1156ce3fa7c69dc`。完整安装命令形式：

```bash
/新的venv/bin/python -m pip install --no-index --no-cache-dir --require-hashes --find-links /已校验的完整wheel目录 -r requirements/robot-ml-jetpack51.lock
/新的venv/bin/python -m pip check
```

不能只执行以上安装命令便宣称通过：还应检查模块实际路径和架构，并用固定图、固定模型运行项目的 YOLOE 子进程。只有验证通过的新 release 才显式选择此环境；旧 release 和原 ML venv 保留，回退时恢复其原配置。ROS、Web/Core 与 SDK 环境不与 ML 合并。
